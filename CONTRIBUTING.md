# Contributing

This repository is intentionally narrow. Contributions should preserve the consumer-witness question rather than expand Negative Result Warrant semantics.

Useful contributions include:

- counterexamples where SDK-only metadata reaches model history;
- cases where malformed or mismatched NRW evidence reaches the effect;
- compatibility fixes required by a pinned Agents SDK release;
- clearer reproduction or provenance checks.

Do not add a live model dependency, a live Algolia dependency, or new provider semantics merely to increase coverage.
